# 檸檬的營養與食材參考

呈現摘要：檸檬｜去皮生檸檬每100克：維生素 C 53毫克、膳食纖維2.8克。這是果肉原料數據；過濾果汁與浸泡液應另行區分。

適用食材：檸檬。
參考形式：去皮生檸檬。每 100 克參考值：維生素 C 53 mg；膳食纖維 2.8 g。
以柑橘酸香搭配飲品；完整果肉含纖維，過濾果汁與浸泡液應分別看待。
數值為指定原料的資料庫參考，不換算為本配方每瓶含量或宣稱營養功效。
來源：USDA FoodData Central，SR Legacy（2018），Lemons, raw, without peel，FDC ID 167746。查核日期：2026-10-02。
