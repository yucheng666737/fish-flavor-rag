# 薄荷的營養與食材參考

呈現摘要：薄荷｜新鮮胡椒薄荷葉每100克：鈣243毫克、鉀569毫克。葉片營養數值不等同於浸泡後的茶湯。

適用食材：薄荷。
參考形式：新鮮胡椒薄荷葉。每 100 克參考值：鈣 243 mg；鉀 569 mg。
薄荷葉可增添草本氣息。葉片營養數值不等同於少量浸泡後的茶湯。
數值為指定原料的資料庫參考，不換算為本配方每瓶含量或宣稱營養功效。
來源：USDA FoodData Central，SR Legacy（2018），Peppermint, fresh，FDC ID 173474。查核日期：2026-10-02。
