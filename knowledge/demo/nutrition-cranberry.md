# 蔓越莓的營養與食材參考

呈現摘要：蔓越莓｜生蔓越莓每100克：維生素 C 14毫克、膳食纖維3.6克。與加糖果乾、糖漿或果汁分開比較。

適用食材：蔓越莓。
參考形式：生蔓越莓。每 100 克參考值：維生素 C 14 mg；膳食纖維 3.6 g。
此項是未加工果實；果汁、加糖果乾或糖漿需按各自標示區分。
數值為指定原料的資料庫參考，不換算為本配方每瓶含量或宣稱營養功效。
來源：USDA FoodData Central，SR Legacy（2018），Cranberries, raw，FDC ID 171722。查核日期：2026-10-02。
