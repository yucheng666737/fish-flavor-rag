# 薰衣草的食用花草特色

呈現摘要：薰衣草｜食用花材以花香與風味為特色，可少量搭配飲品。請選擇供食用的花材，勿用觀賞花或芳療精油替代。

適用食材：薰衣草。
食用形式：經確認可食用的薰衣草花材。Colorado State University Extension 將食用花卉用於增添香氣與風味，並列出薰衣草的食用用途。
在飲品中以花香調味角色介紹，少量品嘗、依喜好調整即可。請選擇供食用的花材，勿把花店觀賞花或芳療精油當作飲用原料。此項呈現花草飲食特色，不宣稱提供特定維生素含量、助眠或治療效果。
來源：Colorado State University Extension，Edible Flowers，Fact Sheet 7.237；查核日期2026-10-02。
