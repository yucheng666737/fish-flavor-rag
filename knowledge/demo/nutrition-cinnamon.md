# 肉桂的營養與食材參考

呈現摘要：肉桂｜研磨肉桂粉每100克：膳食纖維53.1克、鈣1000毫克。香料通常少量調味，100克不是建議食用量。

適用食材：肉桂。
參考形式：研磨肉桂粉。每 100 克參考值：膳食纖維 53.1 g；鈣 1000 mg。
肉桂粉屬香料，少量即可帶入溫暖香氣；每100克僅為資料比較單位，不是食用建議。
數值為指定原料的資料庫參考，不換算為本配方每瓶含量或宣稱營養功效。
來源：USDA FoodData Central，SR Legacy（2018），Spices, cinnamon, ground，FDC ID 171320。查核日期：2026-10-02。
