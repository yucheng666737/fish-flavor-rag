# 柳橙的營養與食材參考

呈現摘要：柳橙｜生柳橙可食部每100克：維生素 C 53.2毫克、膳食纖維2.4克。以完整果肉為參考。

適用食材：柳橙。
參考形式：生柳橙（可食部）。每 100 克參考值：維生素 C 53.2 mg；膳食纖維 2.4 g。
果肉提供柑橘風味與膳食纖維；果汁和完整果肉的營養形式不同。
數值為指定原料的資料庫參考，不換算為本配方每瓶含量或宣稱營養功效。
來源：USDA FoodData Central，SR Legacy（2018），Oranges, raw, all commercial varieties，FDC ID 169097。查核日期：2026-10-02。
