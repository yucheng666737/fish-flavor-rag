# 香草的營養與食材參考

呈現摘要：香草｜香草萃取液每100克：總糖12.6克、熱量288大卡。此項不是香草莢或香草糖漿；100克為資料比較單位。

適用食材：香草。
參考形式：香草萃取液（vanilla extract）。每 100 克參考值：總糖 12.6 g；熱量 288 kcal。
此項是香草萃取液而非香草莢或香草糖漿；通常作為香氣調味參考，不是建議食用量。
數值為指定原料的資料庫參考，不換算為本配方每瓶含量或宣稱營養功效。
來源：USDA FoodData Central，SR Legacy（2018），Vanilla extract，FDC ID 173471。查核日期：2026-10-02。
