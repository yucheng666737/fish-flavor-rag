# 玫瑰的食用花草特色

呈現摘要：玫瑰｜食用花瓣可用於茶與花香調味。玫瑰花瓣與玫瑰果是不同食材，請選擇供食用的花材。

適用食材：玫瑰。
食用形式：經確認可食用的玫瑰花瓣。Colorado State University Extension 將玫瑰列為可用於餐飲的花卉；花卉可用於茶、調味與裝飾。
飲品中可用花瓣增添花香；選購供食用的花材，避免花店觀賞花。玫瑰花瓣與玫瑰果是不同食材，不把玫瑰果的維生素數字套用到花瓣茶。此項以花草特色介紹，不宣稱養顏或治療效果。
來源：Colorado State University Extension，Edible Flowers，Fact Sheet 7.237；查核日期2026-10-02。
